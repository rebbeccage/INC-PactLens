# 主题检索、条款联动与证据摘要

## 使用

文件清单按 INC 会议时间线排列，仅显示会议、名称及中文标记。左侧语言决定右侧清单的可选语言；左侧切换文件或语言时，右侧如有同版本译本便同步切换，没有译本则保留当前文件。选择左右文件后进入原件对照。输入“塑料制品禁限”、英文术语、`Article 4` 或原文短语，选择结果后，两侧显示对应条款；另一侧有同版本同语言文件时会一并切换，避免把翻译差异当成版本增删；“全文”恢复整份文件比较。搜索同时检索中英文原文及双语术语，优先列出当前比较文件，每次显示6条标题及来源，支持继续展开。条款内的差异计数与上一处／下一处导航使用同一比较范围。

“有什么区别”默认关闭，所有文档统一按“删除XX”“新增XX”“表述替换XX”分类。仅右稿有的文字归为删除，仅左稿有的文字归为新增，同一位置同时存在增删归为表述替换；方括号及其他标点也按此规则归类。默认显示5条简目，各类显示实际总项数，其余内容可展开。“查看原文”列出逐项增删、左右完整证据与可用页码，“定位原文”回到双栏文本；“右 → 左”仅表示比较方向。

## 模块

| 文件 | 职责 |
| --- | --- |
| `topics.js` | 10类中英文议题词典、关系类型及权重 |
| `research.js` | 条款索引、主题检索、对应关系、保留原文坐标的归一化、局部比较与证据模板 |
| `analysis-worker.js` | 在后台执行比较，界面丢弃过时响应 |
| `source-pages.js` | 7份PDF逐页提取结果的真实页码范围及全文校验值 |
| `source-numbering.js` | DOCX显式自动编号的独立结构元数据，不改写原文 |
| `app.js` | 搜索浮层、联动选择器、版本切换、摘要抽屉、人工对应确认及缓存 |

## 准确性边界

- 检索采用词典扩展及原文匹配，无外部AI服务。命中分为原文、同义词和议题关联；关联不等于法律措辞等义。
- 自动对应依赖唯一标题及已核对的主席案文／辅助文件主题关系。编号相同不足以确认对应；相似内容仅供候选，待用户确认。未匹配的栏位显示灰色“无对应结果”，不回退到全文；已核对的主席稿缺少 Scope 时，小结显示“新增此条款”或“删除此条款”。可多选目标条款，支持一对多及反向多对一，确认记录保存在当前浏览器。
- 对照模式固定比较左右原件，与修订稿分离，不再提供比较范围选项。修订模式的清理预览和两种 Word 导出均使用左侧修订稿，不把版本差异写作用户修订。
- 排版与前置条款／段落编号默认从比较计算中排除，界面不再显示排版开关。原件编号、原始文本及编辑记录保留；正文中的方括号、义务词、否定、年份、比例、数值和交叉引用变化继续比较；有证据的断行断字可合并，不确定连字符保留并提供核查入口。
- 小结由实际增删生成，先按段落及三类操作合并，省略号仅缩短预览；完整增删保留在展开内容中。脚注提取标签与排版噪声不另成类别，不推断约束力或谈判立场。
- PDF页码基于实际逐页提取并校验全文。DOCX、TXT、MD及修改后的研究稿没有可靠页码时显示“页码未提供”。缺失款号显示“款号未解析”，不按文本段落顺序猜测。
- 搜索只查原件及当前左侧研究稿。尚未比较的搜索结果不会宣称存在变化。文件日期缺失时显示“日期未核实”，不会借用会议日期。

## 验证

`npm test`覆盖检索关系、真实第4条、重新编号、人工多条对应、原始坐标、排版与法律措辞区分、所有同语言原件组合的三类覆盖、Scope 缺项、小结方向、页码缺失、DOCX自动编号及研究稿隔离。`npm run check`校验脚本和静态引用；`npm run build`生成可部署的`_site/`。

## 修订与 Word 导出

修订模式提供独立“清理预览”按钮，预览为只读最终稿，不显示搜索标记、增删高亮或修订面板。退出预览后继续编辑，原文与稿件分别保存。

`docx-export.js` 在浏览器内生成标准 DOCX：修订版使用原生 `w:ins`、`w:del` 及段落标记修订，包含可接受或拒绝的净增删；清理版不包含修订标签。导出沿用阅读稿段落、条款标题和原有自动编号，保留全部正文。文件元信息仅使用应用名称，不读取本机用户信息。

备选标题（Alt title / Alternative title / 备选标题）归入前面的主条款，目录不另列。搜索备选标题可定位主条款；条款比较包含备选标题及其后正文，原文和修订记录完整保留。
